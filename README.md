# STAT 428 Final Project — `uiuc.mcmc`

This repository contains the source code, milestones, and deliverables for the **STAT 428 (Statistical Computing)** final project (Track 2: Markov Chain Monte Carlo / Metropolis-Hastings Sampler), including the **`uiuc.mcmc`** R package located in [`pkg/`](pkg/).

---

## Quick Start

### Prerequisites

- **R** (`>= 3.5.0`, developed with R `4.6.x`)
- **GNU Make** (included with Xcode Command Line Tools on macOS or standard Linux build tools)

### 1. Clone and Build via `make` (Recommended)

From the root of the repository, run:

```bash
make
```

Running `make` (alias for `make all`) automatically executes the full setup and build pipeline in order:
1. **`make restore`** — Restores all locked project and development dependencies (`devtools`, `roxygen2`, `testthat`, `MASS`, `knitr`, `rmarkdown`) from `renv.lock` into the local `renv/` library.
2. **`make document`** — Generates `pkg/NAMESPACE` and `pkg/man/*.Rd` documentation from `roxygen2` comments.
3. **`make check`** — Runs `R CMD check` (`devtools::check("pkg")`) to verify package integrity and run the test suite.
4. **`make install`** — Installs the `uiuc.mcmc` package into the project's local R library so it can be loaded with `library(uiuc.mcmc)` in R or R Markdown documents.

### 2. Alternative Setup from an R Console / RStudio

If you prefer working directly inside RStudio or an interactive R session from the repository root:

```r
# 1. Restore project dependencies from renv.lock
renv::restore()

# 2. Generate documentation, run checks/tests, and install the package
devtools::document("pkg")
devtools::test("pkg")
devtools::check("pkg")
devtools::install("pkg")
```

During active development, you can also load changes interactively without reinstalling:

```r
devtools::load_all("pkg")
```

## `Makefile` Targets

All `make` commands should be run from the **repository root**. Every R target (`document`, `test`, `check`, `install`, `build`) automatically depends on `restore`, so running any target on a fresh clone will synchronize `renv` dependencies first:

| Command | Description |
| :--- | :--- |
| `make` / `make all` | Restores `renv` dependencies, generates docs, runs `R CMD check`, and installs `uiuc.mcmc`. |
| `make restore` | Synchronizes the local `renv` library with `renv.lock`. |
| `make document` | Ensures `renv` is restored, then updates `pkg/NAMESPACE` and `pkg/man/*.Rd` via `devtools::document("pkg")`. |
| `make test` | Ensures `renv` is restored, then runs the `testthat` unit test suite in `pkg/tests/` via `devtools::test("pkg")`. |
| `make check` | Ensures `renv` is restored, then runs full `R CMD check` validation via `devtools::check("pkg")`. |
| `make install` | Ensures `renv` is restored, then installs `uiuc.mcmc` into the active `renv` library via `devtools::install("pkg")`. |
| `make build` | Ensures `renv` is restored, then builds a distributable source tarball (`uiuc.mcmc_0.1.0.tar.gz`) via `devtools::build("pkg")`. |
| `make clean` | Removes generated `pkg/man/*.Rd` manuals and built `.tar.gz` archives. |

## Development Conventions

1. **Do not edit `pkg/NAMESPACE` or `pkg/man/*.Rd` by hand.** Always update the `#'` `roxygen2` comments above the functions in `pkg/R/` and run `make document`.
2. **All MCMC and diagnostic algorithms are implemented from scratch.** Per course guidelines, do not use `coda` or external MCMC packages to compute chains or convergence diagnostics.
3. **Loading the bundled dataset:** Once `uiuc.mcmc` is installed (or loaded via `devtools::load_all("pkg")`), the Wisconsin Breast Cancer dataset is immediately available as `breast_cancer` (569 rows, 32 columns).
4. **Adding new R packages:** If you install a new package during development, run `renv::snapshot()` and commit the updated `renv.lock` so the environment stays reproducible.
